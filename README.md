# 织幕

服务于线上长线剧本杀与跑团的自动化互动叙事引擎第一版。

## 当前工程状态

- 根目录为可交互前端原型。
- `backend/` 为 PostgreSQL 正式后端骨架。
- [ARCHITECTURE.md](./ARCHITECTURE.md) 记录数据边界、权限原则与接入顺序。
- [ALPHA_FEATURE_MATRIX.md](./ALPHA_FEATURE_MATRIX.md) 区分真实可用、前端演示和待接入能力。
- 项目不使用 SQLite 过渡层。

## 启动

```powershell
node .\server.js
```

然后访问 `http://localhost:4173`。

## 已包含

- 世界总览
- 可直接处理工作的首页控制台：角色阅读状态、待办入口与能力地图
- 剧情流程图编辑器
- 内容资产库
- 自动化规则管理
- 主持监控台
- 玩家互动视角
- 角色专属剧情与私密信息
- 公共麦、角色私密麦和受邀私密语音房入口
- 五步标准创作教程与测试房间流程
- 由玩家阅读、调查与线索解读驱动的可控剧情演示
- 小说式角色章节、段落重点标记与角色随身笔记本
- 随行为状态变化的玩家场景、玩家进度和运行日志
- 存档与复盘
- 世界设置、导入导出和实体卡接口入口
