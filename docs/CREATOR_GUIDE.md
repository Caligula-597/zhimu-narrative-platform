# 织幕 · 创作者步骤指引

本文档说明从「创建世界」到「正式开跑」的推荐流程。界面内可通过侧栏 创作指引 随时打开。

## 0. 首次 3 分钟体验

适合第一次打开织幕、想快速感受「创作 → 阅读 → 主持推进」链路：

1. 创建剧本：侧栏 **＋ 创建新世界**（或世界总览 / 剧本库入口），走完五步向导，至少写入 1 个角色与 1 段分幕。
2. 创建测试平行房：向导最后一步会自动建立测试房；也可在总览 **平行房** 中新建。
3. 进入玩家视角：顶栏 **玩家入口** → 输入邀请码选角色 → 阅读私人章节 → **我已读完，保存并继续**。
4. 主持台看推进：顶栏 **进入主持台** → 在玩家表看到阅读进度；若配置了 `host_confirm` 规则，待确认事件会出现在队列中。

公开剧本库仅展示已通过审核的剧本。平台**官方示例**（如「小示例」）由运维配置 `OFFICIAL_EXAMPLE_WORLD_ID`，可在首页引导条一键加入；与 CI 测试桩无关。详见 [WORLDS_AND_FIXTURES_ZH.md](./WORLDS_AND_FIXTURES_ZH.md)。

世界总览页顶部的 **「首次体验 · 约 3 分钟」** 引导条会跟踪关键步骤；完成后可点「不再显示」。

---

## 1. 创建世界（五步向导）

1. 选择运行模式：剧本杀 / 跑团 / 混合长线。决定默认角色模板与文案风格。
2. 配置角色席位：为每个角色填写公开身份与秘密；剧本杀模式可导入 TXT/MD 专属剧本。
3. 建立首章内容：写入章节名、分幕标题与正文；后续可在「剧本创作」继续拆分。
4. 选择自动化模板（可点击卡片开关）：
   - 阅读完成后解锁：写入一条「序章读完记录」规则，添加第二段分幕后改为解锁动作。
   - 线索满足后开放场景：写入暂停的占位规则，在编排台创建线索/场景后改条件。
   - 章节结束主持确认：写入 host_confirm 规则，关键节点会进入主持台待确认队列。
   - 卡关弱提示：写入暂停的变量比较模板，正式开跑前再调整。
5. 创建测试房间：系统写入世界、角色、分幕、起始规则与测试平行房，并跳转到「自动化规则」页。

## 2. 编排剧情（剧情编排台）

- 在图谱中创建 章节、场景、线索、调查点、物品 与连线；公共章节会以卡片显示在画布左侧。
- 选中节点可在右侧面板编辑名称、描述与关联字段；章节可 删除当前节点（关联场景/分幕解除绑定，不删正文）。
- 调查点可设置 所需物品；物品在图谱中创建。
- 发布状态：分幕需在「剧本创作」设为 已发布，玩家才能阅读。

### 2.1 线索（编排台 + 线索管理页）

- 编排台：筛选「线索」→ 画布创建节点 → 连线到场景或调查点；调查点完成后可发放该线索。
- 线索管理页：列表搜索、编辑正文/主持提示、批量删除测试线索；「在图谱中定位」跳转到编排台对应节点。
- 可见性：`私密`（仅持有角色）、`房间公开`、`主持可见`——影响玩家端是否能看到标题与正文。
- 空世界可先 载入示例规则（自动化规则页）或浏览 公开剧本库 复制结构思路。

### 2.2 云端附件（账号与资产页）

- 侧栏 **账号与资产** → **内容资产** Tab：上传图片、音频、PDF 等到 Cloudflare R2；在编排台节点面板中关联到场景或线索。
- 删除后进入 14 天回收站，可恢复；配额在同一页的 **账号与会话** Tab 查看。
- 内测期间免费，无充值入口；空间不足时清理附件或联系 support@getzhimu.com。

删除公共章节（如「序章」）：创作中心 → 章节发布控制 → 删除；或编排台筛选「章节」→ 选中 → 删除当前节点。删除后剩余章节序号自动重排；绑定本章的私人分幕与「序章读完」类自动化规则会一并移除。若测试区仍显示旧规则，点 运行发布检查 或刷新页面。

## 3. 配置自动化规则

- 入口：自动化规则 页 → 新建 / 编辑，或空列表时 载入示例规则（写入 4 条可编辑模板，含读完记录、主持确认、线索/场景占位）。
- 可视化编辑：适合「当…则…」；支持全部/任一满足、发放物品、变量比较。
- 主持确认模式：条件满足后不立即执行，而是出现在 主持监控台 → 待确认事件。
- 手动触发：仅 `manual` 模式规则；在主持台「规则运行预览」中触发。
- 保存前系统会校验引用的角色、分幕、线索、场景是否存在。

## 4. 平行运行房与玩家入房

- 邀请码属于 **平行运行房**，不是「世界」本身；创建测试房或平行房时会生成，之后可随时查看。
- **查看 / 复制邀请码**（三处）：
  1. **世界总览** → 右侧「当前进度」卡片 → **玩家邀请码**（复制码、复制玩家链接）
  2. **世界总览** → 「现在可以做什么」→ **邀请玩家入房**
  3. **主持监控台** → 顶栏 **邀请玩家**，或「等待玩家入房」提示条
- 也可点 **管理运行房**，在房间列表里点 **邀请玩家** 打开详情弹窗。
- 玩家端入口：`play.getzhimu.com` 输入邀请码，或打开带 `?join=邀请码` 的链接。
- 顶栏 **玩家入口** 是创作者自测用（以玩家身份进房），不是查看邀请码的地方。
- 主持需先在总览 **选中当前平行房**，主持台 / 存档页才对该房生效。

## 5. 主持监控（开跑阶段）

- 待确认事件：规则触发的关键转折；可单条确认/拒绝，或勾选后 批量处理。
- 玩家表：查看阅读进度、线索、卡关提示；可手动发线索/物品、解锁分幕/场景。
- 规则运行预览：查看各规则当前是否满足（不修改数据）。
- 存档点：收工前创建；需要回滚时在 存档与复盘 选择恢复范围。

## 6. 存档与恢复

- 创作版本（剧本创作）：只恢复章节/分幕正文，不影响运行进度。
- 运行房存档（存档与复盘）：恢复阅读、线索、物品、调查等运行态；可跨平行房（同一世界内）。
- 恢复前建议先创建新存档；「主持时间线」默认不勾选，避免覆盖现有日志。

## 7. 常见创作顺序（推荐）

1. 向导创建世界 + 模板规则  
2. 编排台补场景 / 线索 / 调查点  
3. 规则页把占位规则改成真实引用  
4. 创建测试平行房 → 玩家视角走一遍  
5. 主持台确认待确认事件与手动干预是否正常  
6. 正式开跑前创建首个存档点  

## 8. 公开剧本库（须人工审核）

- 私人创作不需要审核；只有上架 公开剧本库（所有登录用户可见）须审核。
- 入口：世界设置 → 提交公开库审核申请（填写自测与题材说明）。
- 提交后状态为 审核中，通常 3～5 个工作日 邮件回复；请勿重复提交。
- 通过后剧本出现在侧栏「公开剧本库」；未通过会显示审核意见，修改后可再次申请。
- 咨询：`support@getzhimu.com`（正式申请请走世界设置内表单，不要只发微信）。

## 9. 内测配额与付费说明

- 当前阶段：内测 / 早期投入期，不提供订阅或充值入口，所有功能免费试用。
- 账号页展示的是 用量配额（防滥用），不是待付费账单。
- 创建剧本数、云存储、单文件大小触顶时：先清理数据；仍不够请邮件 support@getzhimu.com（运维可手动调套餐）。
- 商业化订阅（Stripe 等）正式对外后再开放，与内测账号无关。

## 10. 更多帮助
