# 织幕版权与侵权申诉指引（草案）

> **状态**：公开 Beta 前法务稿 · 非律师意见 · 上线前须法务审阅  
> **更新**：2026-07-20 · 与 [`USER_TERMS_ZH.md`](./USER_TERMS_ZH.md) 第 3、4 节衔接

## 1. 适用范围

本指引适用于认为织幕平台上的用户内容（公开剧本库、运行房宣传、上传资产等）侵犯你著作权、商标权或其他合法权益的情形。

未经作者、发行方或其他权利人授权，不得把受保护的角色本、公共幕、线索、HO、模组或团录导入织幕，也不得利用平台进行转载、商用或超出授权范围的修改。私有状态不等于取得授权。

## 2. 我们如何处理

收到**有效申诉**后，我们将：

1. 记录工单并在 **5 个工作日内**确认收件（Beta 阶段可能人工处理，节假日顺延）。
2. 对明显侵权或重复侵权内容：先行**限制展示/下载/公开库收录**，并通知被申诉方。
3. 要求被申诉方在 **10 个工作日内**提交反驳说明或授权证明。
4. 根据材料决定：恢复、维持限制、或删除内容；严重或重复违规可限制账号（见用户协议第 6 节）。

## 3. 申诉需包含

请发邮件至 **legal@getzhimu.com**（上线前以产品内公告为准），标题：`[版权申诉] 简要说明`。

| 项 | 说明 |
|----|------|
| 申诉人身份 | 权利人本人或经授权的代理人 |
| 权利证明 | 著作权登记、首发链接、合同摘要等 |
| 侵权位置 | 公开库剧本名/链接、世界 ID、资产文件名、截图 |
| 联系方式 | 可回复邮箱；必要时电话 |
| 真实性声明 | 「本人确信上述内容未经授权，信息真实；愿承担虚假陈述责任」 |

## 4. 被申诉方反驳

若你的内容被临时限制，可通过同一邮箱回复工单，提供：

- 原创过程说明、时间戳、底稿或授权链；
- 认为属于合理使用/已获授权的理由。

我们将在收到双方必要材料后作出决定，并邮件通知双方。

## 5. 重复侵权与账号

同一账号多次有效侵权认定后，我们可能：

- 永久下架相关世界/资产；
- 限制公开库与上传；
- 终止账号（与隐私政策中的数据删除流程一致）。

## 6. 不适用情形

- 剧本玩法机制、通用题材 idea 本身通常不受单一作品著作权保护；
- 私人运行房、未公开内容：请提供可验证的访问路径或我们可核查的房间/世界 ID。

## 7. 联系方式变更

正式 Beta 前本页与联系邮箱可能调整；以产品内「用户协议 / 隐私政策」页脚链接的最新版为准。
