# 三端登录状态故障矩阵

登录状态以服务端 `/auth/me` 为最终事实来源；Cookie 或 Bearer token 只代表“可能存在会话”。只有明确的 HTTP 401 可以把已知用户降为匿名，网络错误和服务端 5xx 必须保留已有用户并显示“暂不可确认”。

| 编号 | 故障/操作 | Creator | Host | Player | 验收结果 |
| --- | --- | --- | --- | --- | --- |
| AUTH-01 | 同标签页登录 | 更新资料与导航 | 进入世界/房间列表 | 进入玩家首页并连接平台流 | token 写入后只产生一次状态变更 |
| AUTH-02 | A 标签页登录，B 标签页停留 | `storage` 后重新 `/auth/me` | 重新探测并加载世界 | 重新探测并恢复平台/房间流 | B 无需刷新即可显示已登录 |
| AUTH-03 | A 标签页退出，B 标签页停留 | 清 UI 后以 `/auth/me` 复核 | 断开房间流并回到登录 | 断开两类流并回到登录 | 不保留旧用户或旧私有内容 |
| AUTH-04 | Cookie/token 到期，普通 API 返回 401 | 标记会话失效 | 清 Bearer 并触发匿名态 | 清 Bearer 并触发匿名态 | UI 与凭证不再分叉 |
| AUTH-05 | 多个 API 同时返回 401 | 幂等退出 | token 只失效一次 | token 只失效一次 | 不出现重复弹窗、重连风暴 |
| AUTH-06 | 页面刷新且 Cookie 有效 | `/auth/me` 恢复用户 | Bearer 恢复用户 | Bearer 恢复用户 | 首屏 checking 后进入已登录态 |
| AUTH-07 | `/auth/me` 网络失败或 5xx | 保留最后用户 | 保留最后用户 | 保留最后用户 | 显示 unavailable，不误退出 |
| AUTH-08 | 旧探测未返回时另一标签页切换账号 | 丢弃旧结果 | 丢弃旧 token 的结果 | 丢弃旧 token 的结果 | 新账号不被旧响应覆盖 |
| AUTH-09 | localStorage 被浏览器禁用 | Cookie 仍可工作 | 内存 token 降级 | 内存 token 降级 | 当前标签页不崩溃，跨页能力明确降级 |
| AUTH-10 | SSE 返回 401 | 统一认证丢失处理 | 停流并回登录 | 停流并回登录 | 不继续轮询私有数据 |
| AUTH-11 | 旧账号请求的 401 在新账号登录后才返回 | 按请求开始时的凭证版本丢弃旧结果 | 只清理实际被拒绝的 Bearer | 只清理实际被拒绝的 Bearer | 新 token 不被迟到的旧 401 清除 |
| AUTH-12 | 已登录时另一次登录/验证码输入失败 | 保留现有会话 | 保留现有会话 | 保留现有会话 | 凭证尝试接口的 401 不等同于当前会话失效 |

发布门禁：`npm run test:auth-matrix` 必须通过；浏览器回归至少覆盖 AUTH-02、AUTH-03、AUTH-06、AUTH-10、AUTH-11、AUTH-12。任何 401 后仍显示旧私人数据、迟到 401 清除新会话，或任何 5xx/错误密码导致当前会话被强制退出，均视为阻断发布。
