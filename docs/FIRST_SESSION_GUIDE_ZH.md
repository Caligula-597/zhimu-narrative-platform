# 织幕 · 如何跑第一场（用户手册）

> **给谁看**：剧本杀作者、主持人、玩家——**不是**工程文档。  
> **内测期**：免费使用，无充值入口。遇到问题见 [USER_ERROR_GUIDE.md](./USER_ERROR_GUIDE.md) 或 support@getzhimu.com。

---

## 织幕三句话

1. **是什么**：给线上长线剧本杀团队用的创作、主持与玩家运行平台。  
2. **解决什么**：不用文档、表格和群聊手动同步进度、线索和规则。  
3. **为什么值得用**：同一个剧本可以稳定开多场、多人、多房间，并可存档复盘。

## 创作者：30 分钟跑通测试房

### 1. 注册并登录

打开创作者应用 → 注册账号 → **验证邮箱**（官方示例与部分功能需要）。

### 2. 创建第一个世界（三选一）

- **最快**：世界总览 → 跟随「首次 3 分钟」条 → **创建测试世界**（向导一键生成角色、分幕、规则、测试房）。  
- **导入**：已有 Word/Markdown → 创作台导入 → 再进编排台补场景与线索。  
- **体验**：先以玩家身份打开 [官方示例](https://play.getzhimu.com/?experience=official) 感受流程。

### 3. 检查能否开玩

世界总览 → **发布前检查**（或设置页）：至少要有角色、可读分幕、一个运行房。

### 4. 创建平行房并拿邀请码

运行房列表 → **新建房间** → 复制 **邀请码** 或 `play.getzhimu.com/?join=邀请码` 链接发给玩家。

### 5. 自己也可进玩家端验证

用同一账号打开玩家端，输入邀请码，选角色，读完第一节分幕。

### 6. 打开主持台

创作者应用 → **主持台**：应能看到玩家阅读进度、待确认事件；可手动发放线索或创建存档。

## 主持人：开房当天 checklist

- [ ] 平行房已创建，邀请码已发到玩家群  
- [ ] 每位玩家选了**不同角色**（同角色不可重复）  
- [ ] 主持台 SSE 已连接（页顶有实时状态）  
- [ ] 了解 **待确认事件**：规则触发后需你点确认或拒绝  
- [ ] 长线本：知道如何 **创建存档** 和 **按域恢复**（存档页）

---

## 玩家：从邀请到进入故事

1. 打开 [play.getzhimu.com](https://play.getzhimu.com)  
2. 输入主持人给的邀请码 → **下一步：选角色**  
3. 选择你的角色席位 → 进入房间  
4. **分幕**：阅读你的私人剧情；读完后点「标记完成」  
5. **探索**：在场景里调查、获得线索  
6. **线索 / 背包**：查看已获得的物品与线索  
7. 没有邀请码？登录后可 **体验官方示例**（需验证邮箱）

## 常见问题

| 问题 | 怎么办 |
|------|--------|
| 邀请码无效 | 核对大小写；问主持人是否删房或重建 |
| 角色已被占用 | 换另一个角色；或让主持人开新平行房 |
| 官方示例进不去 | 先登录并验证邮箱 |
| 读完后主持看不见 | 确认点了「标记完成」；主持台刷新或等 SSE |
| 配额满了 | 内测期联系 support@getzhimu.com 人工扩容 |
