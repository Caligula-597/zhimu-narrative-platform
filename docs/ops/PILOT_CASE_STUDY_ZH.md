## 案例 A · 匿名团队（自助创作 · 4 人长线本）

| 项 | 内容 |
|---|---|
| 团队规模 | 4 人（1 主持兼 DM + 3 玩家） |
| 剧本来源 | 向导一键生成测试世界 + 创作台微调 |
| 导入方式 | 自助，无人工导入 |
| 周期 | 3 天完成首场 |

### 时间线

**Day 0 — 创建**

- 注册登录 → 总览「首次开房向导」五 step，约 **8 分钟** 得到测试世界与邀请码。
- 主持复制 `play.getzhimu.com/?join=…` 发给玩家。

**Day 1 — 首场运行**

- 3/4 玩家在 24h 内完成第一幕私人剧情。
- 1 名玩家卡关：主持端进度表可见「0/1 段」→ 手动发放线索「测试线索」→ 30 分钟内推进。
- 主持端待确认事件 0 条阻塞项。

**Day 2 — 复盘与反馈**

- 存档页创建 checkpoint + 生成 recap。
- 团队结论：下一场需补公共章节摘要；产品内反馈 1 条（UI 文案建议）。

### 关键指标

| 指标 | 值 |
|---|---|
| 首场完成率（至少读毕 1 幕） | 75% (3/4) |
| 主持人工干预 | 1 次（发线索） |
| 复盘 | 已生成 |
| 续约意向 | 愿意第二场 |

### 客户原话（匿名）

> 「邀请码进房比发 PDF 省事；主持台能看到谁没读幕，省得在群里一个个问。」
