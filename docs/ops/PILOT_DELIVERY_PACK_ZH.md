## 1. 开通邮件（套餐已开通）

**主题**：织幕账号已开通 — 接下来 3 步

**正文要点**

1. 登录 [app.getzhimu.com](https://app.getzhimu.com)（与申请邮箱一致）
2. 阅读 [首场指南](../../docs/FIRST_SESSION_GUIDE_ZH.md)：创建/导入 → 开房 → 邀请玩家 → 复盘
3. 三端链接：
   - 创作端（主应用）：创作与总控台
   - 主持端：[host.getzhimu.com](https://host.getzhimu.com)
   - 玩家端：[play.getzhimu.com](https://play.getzhimu.com)

**附件/链接（可选）**

- 导入说明：[IMPORT_SCRIPT_SOP_ZH.md](./IMPORT_SCRIPT_SOP_ZH.md)（需人工导入时）
- Support：`support@getzhimu.com`

## 2. 导入完成邮件

**主题**：剧本已导入 — 请创建测试房

**要点**

- 世界名称、角色数、分幕数（从 OPS/创作者确认）
- 总控台「制作总控台」查看风险卡片；阻塞项需先处理
- 创建运行房 → 复制邀请码 → 玩家端试读一幕

**模板段落**

```
感谢完成首场试跑。

本场记录：
- 运行房：<房间名>
- 玩家入房：<N>/<M>
- 复盘/存档：<有/无>

建议下一步：
1. 根据总控台「下一步」补齐 <线索/规则/分幕>
2. 第二场前在主持端创建 checkpoint
3. 问题反馈：产品内「反馈」或回复本邮件

如需扩容或导入更多剧本，请联系 support@getzhimu.com。
```
