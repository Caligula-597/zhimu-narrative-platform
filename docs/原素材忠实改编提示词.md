# 原素材忠实改编提示词

> 目标：防止 AI 从口播、文章或创作笔记中只提取一个“中心思想”，再生成一个主题相近但因果完全不同的新故事。

## 为什么需要独立门禁

“主题相符”不等于“忠实改编”。模型很容易把复杂素材压缩成一句话钩子，再用熟悉的社会寓言、极端事件或单一象征物完成一个内部自洽的新故事。这个故事可能文笔合格、冲突强烈，却删除了原素材的思考顺序、反例、权力换手和作者真正的锋利之处。

因此流程必须拆成三次独立调用：

```text
完整原素材
→ 忠实改编预检（禁止生成故事）
→ 矛盾账本通过后才生成大纲
→ 成稿与完整原素材反向核验
```

任何一步都不能由后面的文风润色代替。

## 第一阶段：预检提示词

源码入口：`backend/src/prompts/source-adaptation-fidelity.js` 中的 `buildSourceAdaptationPreflightMessages`。

这一阶段明确禁止案名、logline、人物、案件和结局，只允许模型输出：

- 原素材的 thoughtMovement：每一步认识如何被反例推向下一个问题；
- conflictLedger：每组矛盾需要怎样的欲望冲突、议价权变化和延迟后果；
- causalEdges：前一组矛盾如何制造后一组矛盾的条件；
- authorialBoundaries：哪些作者立场不可磨平，哪些问题必须保持开放；
- coverageAudit：遗漏、错误合并、高损压缩和语义换题风险。

预检同样禁止抢先设计人物欲望、稀缺资源和剧情动作。两股冲突压力都必须有原文锚点；素材讨论制度、市场或代际关系时，不得擅自改写成“寻找内在价值”等心理成长。人物承载属于账本通过后的下一阶段。

只有 `coverageAudit.readyForPremise=true`，才允许进入故事概念生成。

模型不能自行宣布通过。`validateSourceAdaptationPreflight` 还会机械检查：每个必须保留的思考阶段是否有独立冲突承载、预检阶段是否提前合并、原文锚点是否真实存在、所有核心冲突是否进入同一因果图。模型即使输出 `readyForPremise=true`，任何一项失败都会被覆盖为不可进入下一步。

自动修复最多进行两轮。两轮后仍有非原文锚点、顺序错误、心理化替换或多个核心机制共用同一承载项时，流程必须停止并转人工锁定；不得无限重试，更不得降低门槛让模型通过。

## 第二阶段：生成门禁

大纲生成必须遵守 `SOURCE_ADAPTATION_GENERATION_BLOCK`：

1. 每组不可合并的核心矛盾都进入同一批人物的共同历史。
2. 前一组冲突必须给后一组留下债务、资格、羞辱、资源、权力或不信任。
3. 一组矛盾必须同时具备人物行动、议价权变化、即时得失、后续反噬和玩家可改变的现实。
4. 只复用名词、场景、台词、象征物或相似主题，不算覆盖。
5. 故事自身再完整，也不能抵消对原素材的 semantic substitution。

`sourceFidelity.premiseElements` 不再只是“至少引用两句原文”。每组不可合并矛盾都要单独登记，并说明人物行动、权力变化和延迟后果。

## 第三阶段：反向核验提示词

成稿评测使用 `SOURCE_ADAPTATION_REVIEW_BLOCK`，独立检查：

- `high_loss_compression`：多组矛盾是否被压成一个中心命题；
- `semantic_substitution`：是否另写了一个语义相邻的新故事；
- `shock_substitution`：是否用极端意象冒充逻辑锋利；
- `debate_listing`：是否只保留议题名词，让角色轮流讨论；
- `stance_neutralization`：是否把作者立场安全配平；
- `causal_isolation`：删除某组矛盾后，剧情是否毫无变化；
- `reversal_loss`：规则换手与赢家反噬是否消失；
- `source_truncation`：输入后半段是否缺失。

其中任何严重问题都必须返回 `sourceFidelity` 高危问题、要求退回 setup 层重构，并禁止导入。

## 输入完整性

提示词无法修复它没有看到的素材。项目已将 brief 的 premise 上限从 4000 字符提高到 12000 字符，评测阶段也从只读取前 2000 字符改为读取完整 12000 字符。若素材超过当前上限，应先分段建立统一矛盾账本，不得直接截取前半部分生成。

## 核心判断句

每次改编审查只问一个最严格的问题：

> 如果删除原素材中的某组核心矛盾，当前故事是否仍能毫无影响地成立？

若答案是“能”，这组矛盾就没有被改编，只是被提及。
