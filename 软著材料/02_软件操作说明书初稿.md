# 织幕长线剧本杀自动化叙事与运营平台软件 V1.0 操作说明书

## 一、软件概述

织幕长线剧本杀自动化叙事与运营平台软件是一套面向线上长线剧本杀、跑团和互动叙事创作运营的 SaaS 软件系统。软件围绕剧本创作、活态故事总览、机制设计、语义大纲与质量校验、内容编排、房间运行、玩家决策、主持权威结算、复盘归档和运营管理形成完整流程。

系统包含四类主要入口：

- 主应用：用于创作者、运营人员和管理员进行剧本世界管理、内容编辑、AI 矩阵生成、房间管理、资产管理和运营查看。
- 玩家端：用于玩家加入房间、阅读角色内容、查看线索、参与投票与私密行动、广场社交、语音互动和查看复盘。
- 主持端：用于主持人监控房间、推进流程、管理玩家状态、处理现场事件和查看运行报告。
- 官网：用于产品展示、公开入口、内测申请、价格展示和商业信息展示。

## 二、运行环境

服务器端运行环境：

- Node.js
- Fastify 5
- PostgreSQL
- 对象存储服务（R2 兼容）
- 可选监控、告警、链路追踪（OTEL）和上传扫描服务（ClamAV / 内置扫描）

浏览器端运行环境：

- 现代桌面浏览器
- 现代移动浏览器
- 支持 JavaScript、HTML5、CSS3 和 SSE 事件通信

部署环境：

- 主应用与 API 部署于 Railway fullstack 托管环境，同域提供 `/api` 能力。
- 玩家端、主持端和官网部署于 Cloudflare Pages 静态站点托管。
- 生产环境通过 API 域名为多端应用提供统一数据能力，分域部署支持独立迭代。

## 三、系统模块

### 1. 账号与权限模块

账号与权限模块用于用户注册、登录、会话维持、OAuth 接入、账号资料管理、权限判断和访问控制。系统通过后端接口判断用户身份和角色，不依赖前端隐藏内容作为安全边界。

主要功能包括：

- 用户注册和登录。
- 游客登录支持。
- OAuth 账号接入。
- 邮箱验证与密码重置。
- 邮箱注册后输入六位一次性验证码，或使用邮件内的一键验证链接。
- 会话 Cookie 管理与会话撤销。
- 账号资料和权益查看。
- Creator、Host、Player 三端分别维护显示名称与头像。
- 账号数据导出与账号删除。
- 角色、房间、世界和运营权限校验（权限矩阵 27 项）。
- 统一错误返回和接口分桶限流。

### 2. 世界与剧本管理模块

世界与剧本管理模块用于创建和管理互动叙事内容。创作者可以建立世界，编辑章节、角色、场景、线索、物品和规则，并对内容进行版本化管理。

主要功能包括：

- 创建剧本世界。
- 使用世界模板快速创建。
- 编辑世界基础信息和封面。
- 管理角色槽位。
- 管理章节与剧本段落。
- 管理场景、线索和物品。
- 管理自动化规则。
- 管理世界标签。
- 查看公开剧本库和内容审核状态。
- 管理世界版本、发布准备状态和修订记录。
- 世界成员协作与邀请。
- 世界审计日志。
- 世界搜索。

### 3. 创作编辑模块

创作编辑模块用于组织长线剧本内容。系统支持按角色、章节、场景和信息层级整理内容，帮助创作者将叙事材料转化为可运行的互动剧本结构。

主要功能包括：

- 角色信息编辑。
- 章节内容编辑。
- 剧本段落管理与段落补救。
- 导入文档并提取结构（PDF、文本、内容包）。
- 生成或调整角色剧本。
- 查看内容完整性和发布准备状态。
- 内容包导入导出。

### 4. 创作者圣经与活态故事总览模块

创作者圣经模块提供结构化创作底座，帮助创作者在长线剧本中维护角色深度、伏笔体系和真相逻辑。

主要功能包括：

- 角色档案管理。
- 伏笔时间线维护。
- 真相重构。
- 文学风格与时代设定。
- 角色关系图谱。
- 创作者总控台聚合视图（生产、洞察、段落、时间线、图谱面板）。
- 从世界简介、灵感、创作宪法、角色、关系、核心事实与章节组装故事脊柱候选。
- 查看一句话故事、整体故事、开场状态、引爆事件、核心冲突、玩家参与前提、行动循环、真相与转折。
- 查看角色故事作用、章节因果主干、结局方向、待决定问题和暂定假设。
- 区分作者已确认、AI 暂拟和待决定内容；比较、采用或放弃候选版本。

### 5. 编排与线索模块

编排与线索模块用于管理故事运行中的关键对象和信息关系。创作者可以维护线索、物品、场景和信息流转关系，为玩家解锁、主持推进和复盘提供基础。

主要功能包括：

- 线索创建、编辑和归类。
- 物品创建、编辑和归类。
- 场景关系维护。
- 调查点管理。
- 故事图谱与自动布局。
- 线索可见性和归属关系管理。
- 线索分享与审计。
- 线索命中率统计。
- 剧情信息结构化检查。

### 6. AI 矩阵与语义大纲模块

AI 矩阵生成模块用于辅助创作者从大纲到角色脚本进行结构化内容生成，并提供质量评估与公平性校验。

主要功能包括：

- 大纲生成与分幕规划。
- 角色脚本生成。
- 实体解锁编排。
- 公平性校验与防剧透门禁。
- 杀手/无辜者推理生成。
- 知识审计。
- 文学风格与时代设定生成。
- 矩阵评估与质量报告。
- 玩家身份覆盖、章节因果与转折、题材资源、证据来源、结局条件和角色责任校验。
- 不符合结构合同的候选进入校验或修复流程，需人工核对后才能继续生产。
- 创作者向导引导（pipeline wizard）。

### 7. 规则引擎模块

规则引擎模块用于描述和执行结构化规则。系统禁止用户直接提交任意 JavaScript 执行，而是通过结构化条件和动作完成规则触发，降低安全风险。

主要功能包括：

- 创建规则。
- 设置规则条件。
- 设置规则动作。
- 规则结构与条件校验。
- 预览规则执行结果。
- 在房间运行过程中触发规则。
- 记录规则执行日志。

### 7A. 机制设计与运行合同模块

机制设计与运行合同模块用于把作者的玩法意图转换为创作者、玩家和主持端共同遵循的结构化交互合同。玩家提交用于表达倾向或秘密承诺，最终运行态仅由具有房间主持权限的操作在服务端结算。

主要功能包括：

- 在创作者驾驶舱打开机制设计工作台。
- 选择公开抉择、资源取舍、证据质证、顺序重建、限时危机或角色承诺等表现形式。
- 回答“反复动作、冲突原因、有限资源、即时反馈、失败推进、题材特异性、结局因果”机制七问。
- 保存作者草稿，或确认为后续生成上下文；未确认内容不会被当作既定事实。
- 统一玩家提示、主持提示、提交模式、截止时间和超时默认方案。
- 将作者内部机制键映射为玩家公开句柄，避免向玩家投影实现细节或剧透信息。

### 8. 房间运行模块

房间运行模块用于将剧本模板转化为一次具体运行实例。每个房间独立保存玩家成员、阅读进度、线索持有、物品状态、事件日志、检查点和复盘内容。

主要功能包括：

- 创建运行房间。
- 邀请玩家加入房间。
- 绑定玩家角色。
- 查看玩家阅读进度。
- 推进章节和阶段。
- 处理主持事件（含延迟事件）。
- 记录房间事件日志（幂等保护）。
- 创建检查点并支持恢复。
- 房间小玩法（mini-games）。
- 初始化并保存房间机制运行态、当前轮次、修订号和轮次开始时间。
- 记录玩家机制提交、主持结算动作及结算前后修订。
- 通过房间事件同步机制状态和提交数量。
- 公开房间列表与广场展示。

### 9. 玩家端模块

玩家端用于玩家参与剧本运行。玩家可以登录或通过邀请进入房间，查看与自己角色相关的内容，阅读章节，查看线索，参与社交互动，并在结束后查看复盘。

主要功能包括：

- 加入房间。
- 查看角色首页。
- 阅读角色章节。
- 查看已获得线索。
- 查看物品和任务。
- 玩家笔记。
- 线索阅读、分享与备注。
- 投票与私密行动。
- 查看当前机制选择、公开说明、选项代价与风险。
- 提交公开倾向或秘密承诺，并查看自身最新提交状态。
- 在限时机制截止前修改提交；截止后等待主持按作者预设方案结算。
- 怀疑度与口供。
- 玩家任务。
- 参与广场和社交互动。
- 语音房间参与。
- 查看复盘内容。
- 使用移动端友好的导航。

### 10. 主持端模块

主持端用于主持人在运行过程中进行监控和控制。主持人可以查看房间状态、玩家进度、成员情况、事件记录，并执行推进、确认、延迟、踢出等管理动作。

主要功能包括：

- 查看房间总览。
- 查看玩家列表和角色绑定。
- 查看玩家进度。
- 推进房间事件。
- 发放线索与物品。
- 解锁内容。
- 管理主持确认流程。
- 查看每个机制选项的提交数量；公开倾向可查看角色分布，秘密承诺仅主持端可见承诺人与内容。
- 根据玩家讨论与提交汇总确认最终选项；玩家提交不直接改变权威运行态。
- 查看服务器轮次时钟和剩余时间；到期前禁止提前执行默认后果，到期后按作者预设默认方案结算。
- 以当前运行修订号执行结算，处理过期页面或并发操作引起的修订冲突。
- 处理延迟事件。
- 处理玩家异常状态（踢出、催促）。
- 小玩法控制。
- 规则预览与触发。
- 查看事件日志与运行报告。

### 11. 资产与上传模块

资产模块用于管理封面、剧本资料和相关文件。系统支持对象存储、上传策略、文件回收和安全扫描，生产环境配置严格上传检查。

主要功能包括：

- 上传世界封面。
- 上传剧本相关资产。
- 按账号权益检查世界数量、单文件大小和剩余存储容量。
- 上传前预留容量，确认后计入实际占用，失败或取消时释放预留。
- 查看资产列表。
- 删除和回收资产。
- 对上传文件执行安全扫描（内置扫描 + ClamAV）。
- 配置对象存储（R2）。

### 12. 存档与复盘模块

存档与复盘模块用于记录房间运行状态、阶段进展和最终结果。系统支持检查点、恢复、房间事件日志和复盘叙事生成，便于主持人与玩家回顾过程。

主要功能包括：

- 创建房间检查点。
- 恢复房间状态。
- 记录关键事件。
- 生成复盘摘要与叙事。
- 查看玩家复盘页。
- 导出或查看归档内容。

### 13. 账号权益、配额与模型连接模块

该模块用于管理账号权益、创作与存储配额，以及用户自备模型连接。V1.0 不向普通用户开放平台积分、付费套餐或平台自有 API 额度。

主要功能包括：

- 查看账号权益、世界数量和存储配额。
- 用户 LLM 连接配置（创建、激活、测试）。
- 选择 DeepSeek、OpenAI、OpenRouter、通义千问、智谱 GLM、SiliconFlow 或自定义 OpenAI 兼容接口。
- API Key 加密保存并仅按用户授权调用。

### 14. 运营管理模块

运营管理模块用于平台运维、内测支持、内容审核、公开库管理、用户反馈和生产状态查看。管理员可以通过 OPS 页面查看系统健康状态和生产门槛。

主要功能包括：

- 查看系统健康状态。
- 查看生产可信门槛（productionTrust 7/7）。
- 查看告警与监控配置。
- 管理公开剧本库与内容审核。
- 管理内测申请。
- 查看用户反馈与满意度。
- 查看计费和权益相关状态。
- 管理计划升级请求。
- 审计日志查看。

### 15. 官网模块

官网模块用于产品展示、公开入口和商业信息展示。

主要功能包括：

- 产品介绍与真实截图展示。
- 价格与套餐展示。
- 内测申请表单提交。
- 商业版信息展示。

## 四、典型操作流程

### 1. 创建剧本世界

1. 用户登录主应用。
2. 进入世界管理或创作者首页。
3. 点击创建世界，可选择使用模板。
4. 输入世界名称、简介、类型和基础设定。
5. 上传世界封面。
6. 保存后进入创作编辑界面。
7. 继续添加角色、章节、线索、物品和规则。

### 2. 编辑角色与章节

1. 进入指定世界。
2. 打开创作编辑模块。
3. 选择角色管理，创建或编辑角色槽位。
4. 选择章节管理，创建章节内容。
5. 为不同角色配置可见内容。
6. 保存修改并检查完整性。
7. 在创作者圣经中补充角色档案与伏笔。

### 3. 使用 AI 矩阵辅助生成

1. 进入创作向导或 AI 生成入口。
2. 输入创意简介与基础设定。
3. 生成大纲与分幕结构。
4. 检查玩家身份、章节因果、题材资源、证据、结局和角色责任的语义校验结果。
5. 生成角色脚本与实体解锁。
6. 执行公平性校验与防剧透门禁。
7. 生成杀手/无辜者推理与知识审计。
8. 设置文学风格与时代设定。
9. 查看矩阵评估与质量报告。
10. 将人工核对后的内容导入创作编辑器继续调整。

### 3A. 组装活态故事总览

1. 在创作驾驶舱打开“当前故事总览”。
2. 检查可参与装配的世界简介、创作宪法、角色、关系、核心事实和章节材料。
3. 点击“组装第一版故事”或“重新组装候选”。
4. 核对故事主干、角色作用、章节因果、结局方向和待决定事项。
5. 比较当前版本与候选版本，选择采用或放弃。
6. 将确定区块标记为“作者已确认”；后续重新装配会保留这些内容。

### 4. 管理线索和物品

1. 进入编排或线索模块。
2. 新建线索，填写名称、描述、关联章节和可见规则。
3. 新建物品，填写名称、说明和持有关系。
4. 维护调查点与故事图谱。
5. 保存后在房间运行过程中按规则或主持操作进行发放。

### 5. 配置自动化规则

1. 进入规则模块。
2. 创建新规则。
3. 设置触发条件，例如章节进度、玩家状态或线索状态。
4. 设置执行动作，例如解锁内容、发放线索、记录事件。
5. 使用预览功能检查规则结果。
6. 保存并应用于运行房间。

### 6. 创建运行房间

1. 在主应用中选择已准备好的世界。
2. 点击创建房间。
3. 配置房间名称、参与人数和运行参数。
4. 生成邀请链接。
5. 将邀请链接发送给玩家。
6. 玩家加入后绑定角色并开始阅读。

### 7. 玩家加入与阅读

1. 玩家打开邀请链接。
2. 登录或进入玩家端。
3. 加入指定房间。
4. 选择或确认角色。
5. 查看角色首页和章节内容。
6. 按主持推进或规则解锁继续阅读。
7. 查看线索、物品和任务。
8. 记录笔记，参与投票或私密行动。
9. 查看复盘内容。

### 7A. 玩家提交机制决策

1. 玩家在角色主页打开当前轮次的机制选择卡片。
2. 阅读公开问题、选项说明、代价、风险和剩余时间；页面不显示作者内部机制键。
3. 选择一个可用方案并提交；角色承诺类选择按秘密模式发送，其他选择作为公开倾向发送。
4. 服务端核对房间成员身份、角色绑定、当前运行修订和截止时间后保存提交。
5. 截止前再次提交时，以同一玩家和角色的最新选择为准；页面显示自己的最新提交结果。
6. 玩家等待主持人确认最终结算，不能把提交数量或多数倾向直接视为最终结果。

### 8. 主持推进房间

1. 主持人进入主持端。
2. 选择目标房间。
3. 查看玩家加入情况和阅读进度。
4. 按流程推进章节、发放线索或处理事件。
5. 管理主持确认流程与延迟事件。
6. 查看事件日志确认操作结果。
7. 在关键节点创建检查点。
8. 房间结束后查看运行报告。

### 8A. 主持端权威结算

1. 主持人在“机制运行”区域查看当前轮次、资源、证据、待决选择和玩家提交汇总。
2. 核对选项代价、有效证据、玩家公开倾向或秘密承诺，不替玩家补填未提交内容。
3. 在限时机制到期前选择正常方案；到期后仅使用作者预设的默认方案，系统阻止提前默认或到期后的普通结算。
4. 提交结算时携带当前运行修订号；若房间已经被其他操作更新，重新读取状态后再决定，避免旧页面覆盖新结果。
5. 服务端校验主持权限、作品绑定、截止时间和修订号，写入唯一权威运行态，记录审计动作并推送机制状态事件。
6. 玩家端接收公开结算结果和新轮次状态；秘密提交详情不向其他玩家广播。

### 9. 玩家广场与社交

1. 玩家进入玩家端广场页面。
2. 查看公开房间列表。
3. 参与平台社交互动。
4. 查看公开事件流。

### 10. 复盘与归档

1. 房间结束后进入复盘模块。
2. 系统汇总玩家进度、线索、事件和关键记录。
3. 生成复盘摘要与叙事。
4. 玩家在玩家端查看复盘结果。
5. 主持人或运营人员查看归档记录。

### 11. 运营管理

1. 管理员进入主应用 OPS 页面。
2. 查看系统健康状态和生产门槛。
3. 查看审计日志与用户反馈。
4. 管理公开剧本库审核与内测申请。
5. 处理套餐升级请求。

## 五、异常处理

系统对异常情况提供统一提示和后端校验：

- 未登录或会话失效时，提示重新登录。
- 权限不足时，禁止访问目标资源。
- 表单数据不完整时，提示补齐必填项。
- 房间或世界不存在时，返回明确错误。
- 上传文件不符合要求或安全扫描未通过时，拒绝上传并提示原因。
- 接口触发限流时，返回限流提示。
- 生产配置缺失时，OPS 状态页显示未达标项。
- 服务不可用时，展示 503 错误页或离线提示页。

## 六、系统安全说明

系统采用后端权限判断作为主要安全边界，并提供以下安全能力：

- HttpOnly 会话 Cookie。
- OAuth 安全接入与返回来源校验。
- API 分桶限流。
- CORS 控制。
- CSP 安全响应头（enforce 模式）。
- Trusted Types 与受控安全 DOM 写入边界。
- 六位邮箱验证码、重发冷却、错误尝试限制和邮件一键验证。
- 上传安全扫描（内置 + ClamAV + webhook）。
- 操作审计日志。
- OPS Token 与 Metrics Token 鉴权。
- PostgreSQL Row-Level Security（44+ 表启用）。
- 统一错误格式与请求 trace id。
- Sentry 错误捕获。
