## 四、功能摘要

织幕是一套面向线上长线剧本杀、跑团和互动叙事运营场景的 SaaS 软件平台。系统提供创作者端、玩家端、主持端和运营管理能力，支持剧本世界创建与模板引导、角色与章节管理、创作宪法与真相链、活态故事总览与作者确认、机制设计工作台、语义大纲生成和结构化质量校验、线索与物品编排、故事图谱、调查点、自动化规则、AI 玩家测试、房间运行、玩家加入与角色绑定、玩家机制决策提交、主持端权威结算与超时默认方案、SSE 实时同步、事件日志、投票与私密行动、语音互动、检查点恢复、复盘归档、资产配额与安全上传、三端独立用户资料、权限控制、安全审计和生产运维管理。

## 五、技术特点摘要

- 采用 Fastify 5 构建后端 API，以 PostgreSQL 作为主要数据存储，生产环境仅使用真实数据库。
- 采用多端 Vite 前端架构，包含主应用、玩家端、主持端和官网四端，共享层抽出 session token、api-fetch、toast、status-chip、SSE 等跨端能力。
- 按领域拆分后端路由、服务和数据访问模块，覆盖账号、世界、创作、故事助手、编排、规则、房间、主持、玩家、线索、资产、复盘、语音、权益与运营等模块；路由层不直接访问数据库。
- 采用会话 Cookie、OAuth、六位邮箱验证码、密码重置、权限矩阵、限流、CSP enforce、Trusted Types、安全 DOM、上传扫描、审计日志和 PostgreSQL Row-Level Security 等安全能力。
- 支持 SSE 实时事件、房间事件日志与幂等、存档检查点和复盘叙事生成。
- 支持机制三端闭环：创作者定义机制表现和机制七问，玩家提交公开倾向或秘密承诺，主持人查看汇总并执行唯一权威结算；服务端校验房间权限、运行修订、截止时间和作品绑定。
- 限时机制使用服务器轮次时钟和作者预设默认方案；到期前禁止提前执行默认后果，到期后普通结算被阻止并引导主持人按默认方案处理。
- 玩家投影隐藏作者内部机制键；秘密承诺仅向主持端提供身份和内容，其他玩家只接收公开结果及自身提交状态。
- 支持 AI 矩阵与语义大纲流水线：大纲、分幕、角色脚本、实体解锁、公平性校验、玩家身份与章节因果校验、证据与结局合同、知识审计、文学风格与时代设定。
- 支持创作者圣经和活态故事总览：综合世界简介、角色、关系、核心事实与章节形成故事脊柱候选，区分作者已确认、AI 暂拟和待决定内容。
- 支持 Creator、Host、Player 三端独立显示名称与头像，以及世界数量、单文件大小和存储容量配额。
- 支持生产环境健康检查、OTEL 链路追踪、Prometheus 指标、告警 webhook、备份恢复演练和运维状态面板。
- 支持账号权益与配额底座；平台积分、付费套餐和平台自有 API 额度在 V1.0 内不对普通用户开放。
