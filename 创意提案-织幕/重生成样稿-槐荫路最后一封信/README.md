# 《槐荫路最后一封信》

六人现代情感推理本。背景为 1996 年夏，一座即将拆除的旧邮电所。全本无超自然设定，核心案件与十八年前的一场洪灾相连。

建议时长约三至四小时，三幕结构。玩家角色为江雁回、罗启川、陈停云、袁素、沈砚秋、唐竞。

## 文件边界

- `作者层/00_创作合同.md`：类型承诺、关系密度和写作边界。
- `作者层/01_唯一真相与双时间线.md`：唯一真相、旧案和今夜的精确后台时间线。
- `作者层/02_关系图与知识矩阵.md`：仅供作者和主持人核对，严禁交给玩家。
- `作者层/03_人物行为与叙事差异.md`：人物决策模型、时间记忆和关系中的情绪变化。
- `主持层/03_主持人手册.md`：开场、分幕、发放、讨论与结局执行。
- `主持层/04_线索与道具全文.md`：可打印的调查资料和六封信。
- `玩家层/00_人物登场册.md`：所有玩家共同可见的人物资料。
- `玩家层/01_江雁回.md` 至 `06_唐竞.md`：每人一册，只含人物亲历叙事。
- `玩家层/分幕任务卡/`：随对应章节单独发放，只写阶段结果，不提供玩法攻略。
- `质检/05_一致性与越界复核.md`：交付前的通过/阻断记录。

玩家角色本没有行动建议、发言策略、公开与隐瞒清单、证据编号、关系结论或主持流程。主持信息和内部编号只存在于主持层及作者层。
