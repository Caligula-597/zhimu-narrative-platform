# 结构化案例包（可导入体验）

扫描件（JPG/PDF）**不作为**自动正文来源。本目录提供两个剧本的结构化内容包，导入后可在创作端 / 主持端 / 玩家端完整体验。

| 案例键 | 来源文件夹 | 覆盖能力 |
|---|---|---|
| `cheese-6p` | `案例/谁动了我的奶酪 6人` | 6 角色分幕、外形矩阵、日记/目录物料册、搜证耗尽、歌谜/密码锁、双主持说明 |
| `qinglou-561` | `案例/561青楼` | 6 角色分幕、拍卖银票、搜证令牌、衙门令毁证、双主持分工、密码锁/顺序小游戏 |

## 导入

需要已配置 `DATABASE_URL`，且 `FIXTURE.hostUserId`（见 `backend/scripts/fixture-constants.mjs`）具备建世界权限。

```bash
# 先应用迁移（含 115 物料册发放 / 搜证计数）
# 再导入：
node backend/scripts/import-case-fixture.mjs cheese-6p
node backend/scripts/import-case-fixture.mjs qinglou-561
```

成功后会打印 `worldId` 与导入计数（角色、线索、物料册等）。

也可在创作者端用「内容包导入」上传同等结构的 JSON（`format: zhimu-world-package`）。

## 开房体验清单

1. 用导入的世界创建房间，任命主主持（可选协主持）。
2. 主持端点「发物料册」发给目标角色；玩家端线索区出现「物料册」及正文页。
3. 主持端小游戏模板可同步歌谜 / 密码锁 / 顺序题到玩家端。
4. 机制运行台初始化搜证资源；调查动作会扣次数并持久化。
5. 双主持面板会展示案例包里的分工备注（`caseHostNotes`）。

线下扫描件仍可按原文件夹人工发放或上传为资源附件，不替代本包正文。
