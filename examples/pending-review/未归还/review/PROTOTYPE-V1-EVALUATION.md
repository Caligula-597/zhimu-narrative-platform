# 《未归还》可试玩原型 V1 测评

> 结论：**可以进入一桌受控真人首测；不能据此标记为精品、正式示例或可发布内容。**

评审日期：2026-08-12

## 本次测了什么

初轮评审覆盖 `prototype-v1` 的两份主持文件、八个证据包、四份第一幕私人资料和结构化原型合同；信息隔离盲测后又新增一份桌面工具卡，当前共三份主持文件。

评审分三层：

1. **确定性门禁**：来源归属、出现幕次、泄底词、事实核验组合、拒绝路径、四项终局权力与结局优先级。
2. **DeepSeek 压缩模拟**：合作但自保、防御与拒绝、冲动传播三种桌况。
3. **修订后复核**：只核对五项高风险规则，不再让模型自由发挥剧情。

## 确定性结果

- 基础合同测试：7/7 通过。
- 可试玩原型初轮测试：14/14 通过；盲测修订后扩展为 18/18 通过。
- 源码与中文编码检查：通过。
- `git diff --check`：通过。

关键断言包括：

- 十二个来源恰好分入八个证据包，持有人和幕次没有漂移。
- 第一幕材料不能提前证明带走、放行、报损动机或授权结论。
- F4 必须是 E05 + E07，再加 E08 或 E09 任一；基础两张不能自行闭环。
- E09 的录音与剪辑时间线是一张不可拆分的来源卡。
- 何溪拒绝揭箱不会抹掉 E01 + E02 对“2001 年存在第 17 箱”的证明，只让“今夜箱已寻回”保持待核。
- 沈闻川 23:20 不答复时主持不得代选，第 9.3 条资格关闭。
- C → B → A → D 固定结算；正常签约与维持冠名在未触发 C/B 时必然落 A，不能误判为 D。

### 模拟稳定发现的优点

- 四名角色都能通过是否释放独占材料改变公共事实，不只是发表态度。
- 结局由证据、23:20 程序状态和四份签名动作共同产生，因果容易追溯。
- “材料属于公共馆藏”和“原始内容可立即公开”被明确拆开，终局不只剩公开/隐瞒二选一。
- 拒绝不会让主持强制揭底，仍会留下 A、C 或 D 的可结算后果。

### 模拟暴露并已修订的问题

1. **E09 可能被误拆。** 已明确同一 E 编号下的 A/B 小节是一张卡，公开时不能只放有利的一半。
2. **23:20 不答复缺少处理。** 已增加“未答复”状态，关闭主动更正资格，主持不得代选。
3. **END-C 有评判玩家的口吻。** 已删去“勇气不能替别人签授权”的结论句，改为并列呈现事实被看见与传播选择丧失。
4. **文书阅读可能打断节奏。** 每轮发卡增加 60 秒静默阅读，只让持有人指出重要一行；主持不能代为概述含义。
5. **何溪的幕末选择容易被理解成强制台词。** 已说明说与不说都是有效动作，并精确区分历史存在与今夜寻回。

## 为什么不能盲信模拟报告

第一轮自由模拟同时出现四处可验证误判：

1. 在 E05 + E07 + E09 已公开时仍把 F4 判为未核验。
2. 在梁芷正常签约、沈闻川维持冠名时把结局误判为 D，正确结果是 A。
3. 把 E07 错交给沈闻川公开，实际持有人是梁芷。
4. 把何溪拒绝揭箱错误解释为 F2 无法核验；F2 的最低组合本来就是 E01 + E02。

这些错误没有被当成正文依据，而是全部转成了确定性测试。修订后复核对五项规则均判定通过，未发现跨规则矛盾。

## 仍必须由真人桌测回答

- 第一幕玩家能否在 20 分钟内自然理解“临时编号”和“正式入藏”的区别。
- 第二幕五张来源卡是否造成阅读堆积，尤其是 E06、E08、E09 连续公开时。
- 何溪第一幕没有来源卡，是否仍能凭归还条件与幕末决定获得足够存在感。
- 玩家会不会把“经授权摘要”误解成粉饰，或把原始公开自动当成更勇敢的答案。
- 23:20 的程序选择是形成真实压力，还是像一道作者设置的考试题。
- END-A 与 END-C 的结局朗读是否呈现后果而不评判玩家。
- 四名玩家在复盘时，能否说清自己扣住了什么、因此关闭了哪条路径。
