# 周慕｜第二幕：保管人

> 现在才打开。你收到不可拆分的 E09。

## E09 为什么必须整张处理

A 部分是沈启明完整录音：他承认看见何岚带走、没有阻拦、故意填写洪损记录，也说出自己害怕失去名声。

B 部分是你的剪辑工程：删掉 41 秒、删掉后续解释、新增“独自完成”字幕。两部分同属一个来源组，提交时不能只交沈启明的承认而隐藏自己的编辑记录。

## 你的选择代价

- 提交 E09：F3、F4、F5 的关键链条可能形成，你也坐实职业失范。
- 扣留 E09：你保住暂时的作品声誉，却可能同时关闭三个事实的核验路径。
- 只口述有利片段：可以骗角色，却不能被主持计入事实。

## 你的第二幕任务

1. 明确处理 E09：整张提交或当桌承认扣留。
2. 回答为什么删掉的恰好是何岚、17 号和假记录，而不只是“片长不够”。
3. 要求沈闻川承认方向性压力，也承认最终编辑决定是你的。
4. 在没看到 E11 前，不承诺上传箱内原始录音；你可以承诺撤掉旧版。

## 你最危险的诱惑

把自己包装成“刚刚发现完整真相”的人，然后用一次激进曝光掩盖过去的主动删节。
