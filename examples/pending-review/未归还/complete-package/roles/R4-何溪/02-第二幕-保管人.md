# 何溪｜第二幕：保管人

> 现在才打开。你收到 E06。

## 日志给你的不是免责

何岚写明自己主动带走、没有书面许可，也写明三次归还询问和长期保管。她保护了材料，但知道材料不属于自己。

项目办公室撤销、授权限制和机构三次拖延解释了她为什么不轻易转交；它们不能让二十五年的私人控制变成毫无问题。

## 你的第二幕任务

1. 决定是否提交 E06。它会帮助证明何岚带走，也会让家属面对越权保管。
2. 不把“没人拦我”说成沈启明亲眼看见；这需要另一个独立来源。
3. 回答：你要馆方承认何岚的什么——组织贡献、保护行为、长期控制，还是三者都写？
4. 若有人接受你的归还条件，立刻说清你下一步愿意提交哪张材料或选择哪种保管方式，不用同一条件继续拖延。

## 你最危险的诱惑

把“何岚应该被写回历史”偷换成“何岚当年的每个决定都正确”，然后把另一个复杂人物换成新的唯一英雄。
