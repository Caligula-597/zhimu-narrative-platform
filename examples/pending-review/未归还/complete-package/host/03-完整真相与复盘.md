# 《未归还》完整真相与复盘

> 主持私用。结局读完后才可公布。本文件不是玩家推理中的线索。

## 一、2001 年完整经过

2001 年，临川市公共文化种子计划资助青禾职工阅览室采集十二名工人关于旧厂溶剂泄漏与善后的口述。项目材料在 7 月 18 日完成装箱和临时编号，按约应交阅览室永久保存，但还没盖正式验收章。

当天下午洪水倒灌。何岚拿着清册组织居民包裹、传递与装车；沈启明违规开出封存厂车，承担处分风险，两人的贡献都真实且不可替代。

17:40，厂方担心口述材料影响次日上午的生活区安置协议，要求“暂缓入藏”，没有要求销毁或报损。沈启明同意暂缓。何岚判断箱子留在厂内可能消失，在没有书面许可的情况下把它带走。18:12，沈启明看见她经过装车口，没有阻拦，也没有建立归还手续。

记者只刊出沈启明驾驶最后一车的照片，“一个人救馆”的叙事由此形成。次日，沈启明把 17 号填成“洪损未回收”，同时保护何岚与材料、避免安置重谈，也保护正在形成的个人声誉。

## 二、二十五年的两种沉默

沈启明用救馆声誉筹资建馆，真实做成公共事业，也始终没有完成纠正。他 2019 年写信、2024 年录音，说明他并非毫无反省；未寄出、被剪掉，又说明反省没有自动成为公共责任。

何岚保持箱内材料完整，三次提出带条件归还。项目办公室撤销、授权限制、机构拖延都是真实困难。她也用“等更安全的机构”把临时保护延长成二十五年的私人控制。

两个人都不是纯粹恶人，也都不能靠良好动机消除程序责任。

## 四、公布未核验事实

逐项说明桌上没有核验的 F1–F6。措辞统一：

> “canon 中这一事实成立，但你们今夜没有把所需来源共同放进核验区，因此角色无法把它写进正式方案。”

不要说“你们漏了正确答案”。未核验是玩家行动造成的状态，不是考试扣分。

## 五、退角

请玩家把角色页合上，用自己的名字回答。依次问：

1. 哪两张来源第一次让你改变判断？
2. 你扣留过什么？那张材料保护了你什么，又关闭了哪条路？
3. 如果只把纪念牌上的沈启明换成何岚，问题解决了吗？
4. 你是否准确区分提交核验、登记入藏和对外传播？
5. 结局更像你们造成的，还是像作者判给你们的？为什么？

## 六、主持自查

- 是否曾暗示 B 是正确答案？
- 是否把口述当成来源？
- 是否替玩家解释线索含义？
- 是否因接近截止时间允许终局后补交证据？
- 是否准确执行 C → B → A → D？

任何一项为“是”，本桌结果不能用于评估剧情，只能用于评估主持规则需要怎样写得更清楚。
