## 三、四条人物弧最终在哪里交叉

```mermaid
flowchart TB
    R1["梁芷\n先活下来 → 承认空格 → 决定怎样活"]
    R2["沈闻川\n守住名字 → 打开未寄信 → 承担而非辩护"]
    R3["周慕\n剪出确定性 → 公开自己的删除 → 接受传播边界"]
    R4["何溪\n保护即正义 → 看见私人控制 → 归还决定权"]

    R1 --> CORE["终局共同问题\n是否再次把责任交给‘以后’"]
    R2 --> CORE
    R3 --> CORE
    R4 --> CORE

    CORE --> A["延续\n有人继续用旧版本"]
    CORE --> B["带限制的修复\n四种权力同时承担"]
    CORE --> C["越权公开\n真相成为新的伤害"]
    CORE --> D["分裂或暂停\n留下未完成但可追责的动作"]
```

四人最终不是对同一道道德题给答案，而是分别控制四种不能互相替代的权力：馆方签署、资金与冠名、公众传播、实物与访问。巧合把他们带到同一张桌上，分权决定他们不能靠一个英雄完成结局。
