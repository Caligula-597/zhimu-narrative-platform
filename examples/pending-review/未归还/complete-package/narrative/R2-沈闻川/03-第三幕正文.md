# 沈闻川｜第三幕：名字怎样留下

> 23:20 的基金答复已不可撤回。现在你只能在已打开的行动范围内选择 S1、S2 或 S3。

你从钱包里取出一张旧借书证。

照片上的你十一岁，卡面盖着青禾职工阅览室的蓝章。洪水后的那个夏天，外祖父带你去重新办证。他蹲在窗口外，让你自己写姓名。你写错“闻”字，他没有替你划掉，只叫你在旁边重写一遍。

“名字写错了要改，”他说，“不是把这张纸扔了。”

你已经很多年没想起这句话。

今晚桌上谈的也是一个名字。维持冠名的人会说，沈启明开车、筹资、建馆的贡献没有因为一行假记录消失；去冠名的人会说，名字已经从不完整叙事中获得十年合同收益。两边都说中了部分事实。

真正令你不安的，是你一直把“纠正写法”理解成“扔掉整张纸”。仿佛只要何岚和居民回来，外祖父就必须从历史里消失；仿佛只有继续让他站在中央，才能证明你没有背叛亲人。

可 E08 若已核验，外祖父自己写过答案：做成的事是真的，别人从故事里消失也是真的。

你不需要替他保持无罪。你需要决定，基金是否有能力资助一座会记录出资者错误的公共机构。

## 三种遗产

选择 **S1 维持冠名**，你保住“启明社区图书馆”的合同连续性。基金董事会会松一口气，开馆宣传仍有清楚主角。若梁芷正常签约，项目可能顺利推进。可维持的不只是外祖父姓名，还有一套已被质疑的收益结构：未来十年，每次念出馆名，都会继续默认单人英雄版本无需先纠正。

选择 **S2 启动第 9.3 条**，前提是你在 23:20 没有关闭资格。冠名停止，80% 资助保留，20% 暂扣一年。董事会很可能取消你的继任资格，亲戚会说你把外祖父一生捐出去的钱变成了控告他的证物。但你并没有撤销他的贡献。你只是拒绝让贡献继续购买一个排他的中心位置。

选择 **S3 冻结资助**，基金退出本轮拨款，调查获得最长时间。它能阻止错误合同在午夜落地，也会把馆、员工和居民变成家族内部无法处理争议的代价。如果你选择它，要诚实分辨：这是审慎，还是当你不能控制外祖父怎样被记住时，就把资源一起收走。

何溪也在替何岚守名。你们在今晚最容易成为敌人：一个人害怕祖辈继续被抹掉，一个人害怕祖辈只剩过错。但真正复杂的历史容得下两句并排的话——何岚组织、保管，也长期越权控制；沈启明开车、建馆，也制造假记录并接受名声。

如果一座公共馆容不下这两个人的矛盾，它也不配只留下其中一个人的名字。

你可以把旧借书证放在文件袋上。它不是证据，只是提醒：纠正不是撕毁。

亮牌前说：

> “我愿意付出的代价是……”

别说“我愿意让外祖父被误解”。说清楚你愿意失去哪一份资金、位置或确定感。
