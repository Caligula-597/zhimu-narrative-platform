# 《未归还》可试玩原型 V1

这是从逻辑合同直接落下来的第一版桌面原型，目标不是把所有文字写满，而是验证一条完整体验：

> 发现断号 → 交换带有代价的证据 → 看见四个人都在延续旧叙事 → 区分“提交核验”“登记入藏”和“对外传播” → 分别行使四项不可替代的权力。

## 本批包含

- `host/00-开场与场控.md`：准备、开场朗读、三幕时钟和防卡规则。
- `host/01-事实核验与结算.md`：主持私用的事实核验表、终局动作和四种结局。
- `host/02-桌面工具卡.md`：可裁切的动作说明、条件板、计时条与签名卡。
- `evidence/P01` 至 `P08`：八个玩家实际处理的证据包，共十二个独立来源。
- `roles/R1` 至 `R4`：四名玩家的第一幕私人资料、持有证据和主动任务。
- `prototype-contract.json`：供自动测试使用的分发、门禁和结算合同。
- `START-HERE.md`：真人首桌的打印、装袋和开桌入口。

## 一次纸面试玩的准备方式

1. 主持人单独阅读两份 `host` 文件，玩家不得查看。
2. 四份 `roles` 文件分别私发给对应玩家。
3. 证据包中每个 `E` 标题都是一张独立来源卡。双来源证据包应沿分隔线拆开，交给不同持有人；不能把整包提前给其中一人。同一来源下的 A/B 小节是一张不可拆分的卡，持有人不能只提交对自己有利的半张。
4. `P03 今夜签约` 开场放进核验区；其余来源卡按角色资料和幕次装入信封。
5. 玩家可以隐瞒、撒谎或拒绝提交，但不得伪造卡面文字、抢夺文件或替别人签字。
6. 主持人只记录已经**提交到核验区**的来源。私人剧本里的自述不算公共证据。
7. “提交核验”只是在闭门会议中让四人查看卡片，不等于登记入藏，更不等于直播、上传或展陈。
8. 有条件的交换必须写到条件板上。目标角色接受后，提出者应立即履行；仍不履行就记录为当桌反悔，不能继续用同一条件拖到下一轮。

## 原型边界

- 本版只写到“能完整跑一场”，不是最终文学稿。
- 所有机构、合同、人物和档案均为虚构；第 9.3 条是故事内程序，不是现实法律意见。
- 本版不接入旧项目的任何人物、世界观或谜底素材。
