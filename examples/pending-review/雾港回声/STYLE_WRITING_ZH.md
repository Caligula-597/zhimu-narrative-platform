# 矩阵写作风格标准（v5.4 · 多人私人本）

> **版本**：`v5.4-player-script`  
> **原则**：心理描写是私人本常态；时间用**先后**不用**死钟点**；硬门禁只卡**剧透**与**公平**

---

## 1. 经历段（原 Action）· 先后叙述

**不是什么**：不是监控日志，不是「21:05…21:06…21:07…」流水账。

**是什么**：本幕你经历了什么 — 场景、动作、环境，用**相对顺序**串联。

| | 示例 |
|---|------|
| ❌ 太死 | 21:05 你进入。21:06 你蹲下。21:07 你起身。 |
| ✅ 合适 | 你随众人退回大厅。潮声未歇，你注意到门闩完好。随后有人提起气象表的事。 |
| 时间锚点 | 全幕至多 1～2 个模糊锚点（「入夜后」「风暴稍歇时」） |

**心理**：本段以**外在经历**为主；细腻内心可放在公聊/感受段，但不禁止短句感受。

---

## 2. 公聊与心理段（原 Dialogue）· 多人向常态

**允许**：公开对话 + **你的心思、怀疑、不安、误判** — 这是剧本杀私人本核心阅读体验。

**仍禁止**：
- 未授权物证专名、独家关键事实
- 第三幕前写死「X 是凶手」
- forbiddenFacts / 作案自白

| | 示例 |
|---|------|
| ❌ | 我确定他就是凶手，只有我看见暗格。 |
| ✅ | 「你独自上了灯室。」你心里一紧——对方在诈你，还是真看见了什么？ |

**时间**：用「刚才」「讨论开始前」— 不要死卡 HH:MM。

---

## 3. 公平推理 · 两层信息

| 层 | 说明 |
|----|------|
| **线索卡** | 主持发放的共享调查素材 — 剧本信息的一部分，不是全部 |
| **特色线索** | 每幕 1～2 条，**读本角色剧本才能发现** — 玩家自行决定是否公聊 |

独占个人细节 = **鼓励**，不是 fairness 违规。  
违规 = 推理必需的核心真相锁在一人本且他人永远无法获得。

真凶自知：私人本可直白写「我是凶手、必须瞒住」— 别人看不见，**不扣分**。

---

## 4. 规定情感段

系统注入 `[规定疑惑]` / `[规定情绪]`；可与正文心理呼应，不重复剧透。

---

## 5. 与打分的关系

| 旧标准（已废弃） | 新标准 |
|------------------|--------|
| 心理描写扣分 / strip | **不扣分**；仅剧透自白（「是我杀的」）扣分 |
| 行动段禁「感到/紧张」 | 允许；公聊段鼓励适当心理 |
| 每句 HH:MM | **advisory 提醒**过密；不阻断生成 |
| actionPsychology 硬门禁 | 改为 **spoilerLeak** 硬门禁 |

详见 [SCORING_ZH.md](./SCORING_ZH.md)
